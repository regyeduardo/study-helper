# Introdução à Programação

## O que é Programação?

Programação é o processo de criar um conjunto de instruções que dizem ao computador como executar uma tarefa.

### Exemplo em Python

```python
print("Olá, mundo!")
```

## Conceitos Básicos

- **Variáveis**: armazenam dados
- **Loops**: repetem operações
- **Condicionais**: tomam decisões

### Tabela de Tipos

| Tipo | Exemplo     | Descrição          |
|------|-------------|--------------------|
| int  | `42`        | Número inteiro     |
| str  | `"Olá"`     | Texto              |
| list | `[1, 2, 3]` | Lista de elementos |

> A programação é uma habilidade fundamental no século XXI.
